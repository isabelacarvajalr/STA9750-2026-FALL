Introduction

Netflix has been publishing “What We Watched” reports every 6 months since 2023. The data contains the number of hours watched for each title. This data is very useful to get insights and draw conclusions from the information of the past 3 years. This data was released to help advertisers get a sense of the number of people who would see their ads, and help creators get a sense of viewership in order to check they were getting paid accordingly.

In this report I analyzed the 7 reports that are available which contain data between 2023H1 all the way to 2026H1, and gathered information regarding what types of content are watched the most (in hours). I cleaned the data and created tables in order to have a visual on the data and also provided a strategy memo you can find at the bottom.

Data Acquisition and Cleaning

Show code 
#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 7, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year,
           period,
           period_start,
           period_end,
           Title,
           -half,
           Runtime,
           Views,
           `Hours Viewed`,
           `Release Date`,
           `Available Globally?`,
           live_event) |>
    rename(title = Title,
           runtime = Runtime,
           views = Views,
           hours_viewed = `Hours Viewed`,
           release_date = `Release Date`,
           available_globally = `Available Globally?`) |>
    mutate(
      year = as.integer(year),
      available_globally = available_globally == "Yes"
    )
}

NETFLIX_DATA <- load_netflix_data()

# Heuristic: runtime over 240 minutes (4 hours) = TV show, otherwise movie.
# Titles with no runtime can't be classified and are shown separately.

    is.na(runtime) ~ "Unclassified",

# 0 = viewing spread evenly across titles; 1 = all viewing in a single title
gini <- function(y) {
  y <- sort(y)
  n <- length(y)
  2 * sum(seq_len(n) * y) / (n * sum(y)) - (n + 1) / n
}

This data is very useful to get insights and draw conclusions from the information of the past 3 years. This data was released to help advertisers get a sense of the number of people who would see their ads, and help creators get a sense of viewership in order to check they were getting paid accordingly.

#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
    
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
    
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
   mutate(path = path(data_dir, paste0(period, ".xlsx")), 
          path = map2(url, path, download_if_needed), 
          data = map(path, read_excel, skip=3, na="*"), 
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 7, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year,
           period,
           period_start,
           period_end,
           Title,
           -half,
           Runtime,
           Views,
           `Hours Viewed`,
           `Release Date`,
           `Available Globally?`,
           live_event) |>
    rename(title = Title,
           runtime = Runtime,
           views = Views,
           hours_viewed = `Hours Viewed`,
           release_date = `Release Date`,
           available_globally = `Available Globally?`) |>
    mutate(
      year = as.integer(year),
      available_globally = available_globally == "Yes"
    )
}

# ---- Gini coefficient ----
# 0 = viewing spread evenly across titles; 1 = all viewing in a single title
gini <- function(y) {
  y <- sort(y)
  n <- length(y)
  2 * sum(seq_len(n) * y) / (n * sum(y)) - (n + 1) / n
}

##### Summary
This memo analyzed Netflix's “What We Watched” reports, between the periods 2023–2026. The key takeaways are:
- Series took most of the watch time vs movies
- The global originals perform very well but the share of watch time is going down compared to the past
- The majority of the watch time comes from the broad title catalog and not the top hits.

In year 2027 Netflix should continue to grow and invest in their broad title catalog while keeping the originals and "Comfort Food" shows. They should also invest in TV shows like series or multi season franchises, and finally they should add more regional originals.

##### Global Originals
The global titles are a small part of the catalog representing only `r percent(global_by_title, accuracy = 0.1)` of titles. But at the same time they represent more than half of the watch time with `r percent(global_by_hours, accuracy = 0.1)` of viewing hours.

However, their share of watch time has dropped from `r percent(global_start, accuracy = 0.1)` in 2023H2 to `r percent(global_end, accuracy = 0.1)` in 2026H1.

This means while global titles are still going strong even if a fraction of the watch time fell, regionally available titles are taking a bigger share: `r percent(1 - global_start, accuracy = 0.1)` → `r percent(1 - global_end, accuracy = 0.1)`. To stay ahead, Netflix should keep investing in global originals while adding more regional ones.

##### TV Series vs Movies
The data shows that TV Shows are responsible for most of the watch time and it also grew slightly: `r percent(tv_start, accuracy = 0.1)` in 2023H2 to `r percent(tv_end, accuracy = 0.1)` in 2026H1. On the other hand movies are responsible for a small but steady share: `r percent(avg_movie_share, accuracy = 0.1)` on average. It is important to point out that every #1 title in every period was a series and not a movie.

Netflix should focus its budget for the coming year on series and multi season franchises vs movies since the data is clear that TV Shows are the ones being watched the most hours by the subscribers.

##### Big Hits vs the Long Tail
The Gini coefficient is a score that ranges between 0% and 100% to show how evenly something is divided (in this case, among titles). The closer the score is to 0% the more equally titles share the viewing, while 100% means one single title gets all the viewing.

Netflix's Gini shows subscribers' viewings are highly concentrated since it had a score of `r percent(gini_hours_latest, accuracy = 0.1)` in 2026H1 based on the hours viewed. And even after being adjusted for length to make sure it is fair between long shows and short shows, the Gini is still `r percent(gini_views_latest, accuracy = 0.1)` when measured by views. This has stayed very consistent since 2023H2 as can be seen in the chart below. 

Even though the viewing is concentrated, the data shows the top 10 titles take a very small fraction of watch time in 2026H1: `r percent(top10_share, accuracy = 0.1)`. So the majority of the watch time is spread among the rest of the title catalog.

This gives an important insight to Netflix that they need to keep a broad catalog of titles and not only rely on the top hits. 

##### Recommendations for 2027
- Prioritize series over movies, since we can see TV shows can account for `r percent(avg_tv_share, accuracy = 0.1)` of hours vs `r percent(avg_movie_share, accuracy = 0.1)` for movies.

- Keep the "Comfort Food" licenses and renew them since these shows are being continuously watched by the subscribers and have a steady engagement even if they came out many periods ago. A few examples are: "Breaking Bad" and "Suits".

- Continue investing in the creation of multi season franchises because the data tells us shows like "Bridgerton", "Wednesday", and "Squid Game" are #1 hits and there are returning viewers.

- Keep the broad range of titles and keep investing in having a full content library since the data shows the top 10 titles are only `r percent(top10_share, accuracy = 0.1)` of viewing, and most of the watch time is distributed among smaller titles.
